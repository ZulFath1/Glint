# Glint v0.1.0

The first release of **Glint**, a tiny, buttery-smooth Start menu for
Windows 11, written in Rust. Press the Win key and a small menu grows out of
the taskbar with a soft bounce: search, pinned apps, a music player and a
power button. No ads, no web results, no "Recommended".

## Features

- Grow-from-the-taskbar open/close animation with staggered icons, played by
  the Windows compositor at your monitor's refresh rate
- Instant search across all installed apps (classic and Store), with
  keyboard navigation and launch-count ranking
- A full search box: selection, word jumps, copy/paste, and IME input for
  Chinese, Japanese, Korean and Vietnamese
- Pinned apps grid that sizes the menu to its content; right-click to pin or
  unpin
- Music player for Spotify, browsers, Media Player and more: cover,
  controls, seek bar and source switching
- 4 background modes (solid, gradient, glass, glass + gradient) and 5 color
  presets, with an automatic readability guard
- Power menu: Lock, Sleep, Restart, Shut down
- `config.toml` with hot reload and clear error messages
- Follows Windows animation, transparency, accent color, battery saver and
  high contrast settings
- Optional "Start with Windows" from the tray icon

## Performance (measured on the author's PC)

- Memory (Task Manager's "Memory" column): 5–14 MB hidden, 10–12 MB open
  (the Windows Start menu: ~17 MB)
- CPU while hidden: 0
- One 1.0 MB exe, no installer

## Requirements

- Windows 11 22H2 or newer
- 64-bit (x64)

## Install

1. Download `glint.exe` below and put it in a folder that will stay.
2. Run it. SmartScreen may warn because the exe isn't code-signed: click
   **More info → Run anyway**.
3. Press the Win key.

To uninstall: turn off **Start with Windows** if you enabled it, choose
**Quit Glint** in the tray menu, then delete the exe, `%APPDATA%\Glint` and
`%LOCALAPPDATA%\Glint`.

## Known limitations

- Clicking the taskbar's Start button still opens the Windows Start menu
  (you can hide that button with a Windhawk taskbar mod).
- Search covers apps only.
- No settings window yet; settings are in `config.toml`.
- Tested on one PC so far: multi-monitor setups, other display scales, a
  taskbar on the top or side, and real CJK IMEs have had little testing.
- The 1,000-cycle leak test grows memory by about 1.2 MB, slightly over the
  1 MB goal.
- The exe is not code-signed.
